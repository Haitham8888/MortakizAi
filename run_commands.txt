# 🚀 أوامر تشغيل MortakizAi (vLLM)

هذا الملف يحتوي على أوامر التشغيل المثالية لكل جهاز حسب مواصفاته.

---

## 1️⃣ جهاز الكرت الواحد (16GB VRAM) - الحالي
يستخدم هذا الإعداد نموذج 7B مع سياق (Context) متوازن لضمان الاستقرار.

### لتشغيل نموذج Qwen 7B (الخيار الأفضل والجهاز المستقر):
```bash
python run_ai.py models_cache/models--Qwen--Qwen2.5-Coder-7B-Instruct q3 16384 0.75
```

### لتشغيل نموذج Qwen 0.5B (سريع جداً وخفيف):
```bash
python run_ai.py models_cache/models--Qwen--Qwen2.5-Coder-0.5B-Instruct q3 32768 0.8
```

---

## 2️⃣ جهاز كرتين H100 (188GB VRAM) - الخارق
هذا الإعداد يستغل كامل قوة الكروت ليوفر أطول سياق ممكن (128 ألف توكن) مع أعلى دقة.

### لتشغيل نموذج Qwen 7B (بأطول سياق ممكن):
```bash
python run_ai.py models_cache/models--Qwen--Qwen2.5-Coder-7B-Instruct q3 128000 0.95
```

### لتشغيل نماذج أضخم (مثل 32B أو 70B إذا توفرت مستقبلاً):
```bash
python run_ai.py path/to/large-model q3 64000 0.95
```

## 💡 ملاحظات هامة:
1. **الترتيب في الأمر:**
   `python run_ai.py [مسار_الموديل] [اسم_التقديم] [طول_السياق] [نسبة_الذاكرة]`
2. **الاسم المستعار (q3):** أبقيته كما هو ليتوافق مع إضافات VSCode لديك دون الحاجة لتغيير إعداداتها.
3. **للإيقاف:** اضغط **Ctrl + C** في التيرمينال لتحرير الذاكرة بالكامل.
