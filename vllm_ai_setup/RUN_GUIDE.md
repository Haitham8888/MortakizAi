# 🛡️ أوامر تشغيل مُرْتَكَز (MortakizAi)

هذا الملف يحتوي على الأوامر المثالية لتشغيل محرك الذكاء الاصطناعي المحلي باستخدام `vLLM` بناءً على قوة العتاد المتوفر.

---

## 💻 1. جهاز الكرت الواحد (16GB VRAM) - الإعداد الحالي

*يناسب كروت مثل RTX 4080 (16GB), A4000, أو ما يعادلها.*

### 🚀 الخيار الموصى به (نموذج 7B الذكي)

هذا النموذج يوفر أفضل ذكاء برمجي مع استقرار تام على كرت 16GB.

```bash
python run_ai.py models_cache/models--Qwen--Qwen2.5-Coder-7B-Instruct q3 16384 0.75
```

### ⚡ الخيار السريع (نموذج 0.5B الخفيف)

سرعة فائقة جداً للاستفسارات البسيطة وسياق أطول.

```bash
python run_ai.py models_cache/models--Qwen--Qwen2.5-Coder-0.5B-Instruct q3 32768 0.8
```

---

## 🔥 2. الجهاز الخارق (2x H100 94GB)

*بإجمالي ذاكرة 188GB VRAM - أداء عالمي.*

### 🏛️ الخيار الاحترافي (سياق ضخم 128K)

استغلال كامل لقوة الكروت لقراءة مشاريع برمجية كاملة في طلب واحد.

```bash
python run_ai.py models_cache/models--Qwen--Qwen2.5-Coder-7B-Instruct q3 128000 0.95
```

### 🧠 تشغيل نماذج أضخم (مثل 32B أو 72B)

إذا قمت بتحميل النسخ الأكبر من الموديلات مستقبلاً:

```bash
python run_ai.py /path/to/large-model q3 64000 0.95
```

---

## 🛠️ دليل المتغيرات في الأمر

الأمر مرتب كالتالي لسهولة التعديل:
`python run_ai.py [1] [2] [3] [4]`

1. **مسار الموديل:** المجلد الذي يحتوي على ملف `config.json`.
2. **الاسم المستعار:** الاسم الذي تضعه في إعدادات (Continue/Cline) مثل `q3`.
3. **طول السياق:** أقصى عدد توكنز (Tokens) يمكن للموديل تذكرها.
4. **نسبة الذاكرة:** كم يحجز الموديل من ذاكرة الكرت (0.10 إلى 0.95).

---
**💡 نصيحة:** دائماً استخدم **Ctrl + C** لإغلاق الخادم قبل الانتقال لموديل آخر لضمان تفريغ الذاكرة بالكامل.
