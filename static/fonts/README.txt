خطوط تاجوال (Tajawal Fonts)
=======================

لكي يعمل الموقع بدون إنترنت، ضع ملفات الخطوط التالية في هذا المجلد:

1. Tajawal-Regular.ttf
2. Tajawal-Medium.ttf
3. Tajawal-Bold.ttf

يمكنك تحميل خطوط Tajawal من:
https://fonts.google.com/specimen/Tajawal

بدلاً من ذلك، يمكنك تنزيلها من GitHub:
https://github.com/google/fonts/tree/main/ofl/tajawal

---

To make the site work offline, place the following font files in this folder:

1. Tajawal-Regular.ttf
2. Tajawal-Medium.ttf
3. Tajawal-Bold.ttf

Download Tajawal fonts from:
https://fonts.google.com/specimen/Tajawal

Or from GitHub:
https://github.com/google/fonts/tree/main/ofl/tajawal

ملاحظة: إذا لم تضع الخطوط، سيستخدم المتصفح خط النظام الافتراضي (Segoe UI/Tahoma).
Note: If fonts are not provided, the browser will fall back to system fonts (Segoe UI/Tahoma).
